## 关键发现
**功能已实现**——当前 `app/ui/main_window.py` 的右栏已有 4 个批量按钮（"── 批量 ──"段）：

| 按钮 | 文件位置 | 作用范围 | 行号 |
|------|---------|---------|------|
| ☑ 全选 | `_on_select_all` | 选区（清空旧选区） | ~L433 |
| ▶▶ 全部开始 | `_on_start_all` | **全部** STOPPED → RUNNING | ~L447 |
| ⏸⏸ 全部暂停 | `_on_pause_all` | **全部** RUNNING → PAUSED | ~L462 |
| ■■ 全部结束 | `_on_stop_all` | **全部** 二次确认 → STOPPED | ~L477 |

加上原有的 4 个"检测控制"按钮（"── 检测控制 ──"段），**作用于选区内设备**：
- `开始检测` → 选区内 STOPPED → RUNNING
- `暂停检测` → 选区内 RUNNING → PAUSED
- `恢复暂停` → 选区内 PAUSED → RUNNING
- `结束检测` → 选区内 RUNNING/PAUSED → STOPPED

## 实际可用路径

**"对选中多台设备批量开始/暂停"** 当前已通过以下交互实现：

1. 在主网格上 **Ctrl+左键** 多选目标设备
2. 点击右栏"── 检测控制 ──"段的"开始检测"或"暂停检测"
3. 按钮 label 会自动显示 `(X/Y)` 反馈有多少台会被影响

**"对全部设备批量开始/暂停"** 通过右栏"── 批量 ──"段的"全部开始"或"全部暂停"实现。
