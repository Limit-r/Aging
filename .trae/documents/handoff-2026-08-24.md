## 2. 视频检测整体架构（两页 + 常驻 worker）

用户交互设计：
- **视频总览页** `video_page.py` → `VideoOverviewPage`：只显示各通道信号灯**位点标记**网格（`VideoMarkCell`），**不显示检测结果**。
- 在总览页**双击某位点** → 发出 `open_stream_requested(cid)` → `home_page` 路由切到 `video_stream` 页并 `set_channel(cid)`。
- **视频流检测页** `video_stream_page.py` → `VideoStreamPage`：单通道逐帧视频，左侧实时画面 + 右侧结果面板。

### 常驻 Worker（模型预加载，关键设计）
- 文件：`ml/vision/worker.py`（替代旧 `run_video.py`）。
- 独立长驻进程，**启动时一次性预加载** YOLO（9 类）+ TinyConv（H/L 二分类），加载完成后发 `{"type":"ready", ...}`。之后通过 **stdin 接收 JSON 命令**、**stdout 输出 JSON 事件**，多个检测任务复用同一份模型，避免“开始检测时才加载模型”的卡顿。
- 检测引擎：`ml/vision/engine.py` → `DetectionEngine`（`.detect()` 用 YOLO 定位、`.classify()` 用 TinyConv 判 H/L）。
- 命令：`{"cmd":"detect"|"stop"|"quit", ...}`；事件：`status / ready / fatal / error / sample / done`。
- **逐帧检测（不抽帧）**：保证不漏 LED 闪烁；闪烁计数基于 **off→on 状态翻转**（`FlashTracker`），并排除首/尾各 30 帧的启停噪声（历史约定）。

### GUI ↔ Worker 通信（video_stream_page.py）
- 用 `QProcess`（`setProcessChannelMode(MergedChannels)`）+ `pyqtSignal` 异步收发，不阻塞 UI。
- 注入 `PYTHONIOENCODING=utf-8`、`PYTHONUNBUFFERED=1`。
- 实时画面：worker 每帧把标注缩略图写到 `outdir/cell_{cid}.jpg`，GUI 用 `QTimer`（`VIDEO_REFRESH_MS`=300ms）`_refresh_video()` 读取 → 等比缩放显示。
- worker 显式发送 `hide` 会让 `_refresh_video` 读到空图自动跳过。

## 3. 结果展示（最终形态，视频流页右侧面板）

文件：`video_stream_page.py` → `VsResultPanel`。

- **三张独立折线图**（各占一个 `pg.PlotWidget`），不再是一张图多线，也不写死 VPL/CPL/PWR：
  - **FP 系列** · LED 闪烁
  - **A 系列** · LED 闪烁
  - **其他 系列** · LED 闪烁（后续新增系列自动归入）
- **系列自动区分**：按 LED 位点 ID 基础类前缀聚合。LED ID 形如 `{base}_{slot}`（如 `FP_VPL_0` / `A_CLIP_0`），`_series_of()`：首 token 为 `FP`/`A` 归对应系列，其余归 `other`。
- **area 类不参与统计**：worker `_assign_led_ids()` 会跳过 `*_area`（`name.endswith("_area")` 或 `endswith("area")`），只统计信号灯（CPL/VPL 等）的闪烁。
- 折线：横轴 = 检测秒数，纵轴 = 该系列的**累计闪烁次数**；逐秒（整数秒）采样一个点。
- 三张图放入 `QScrollArea`（`vsSeriesScroll`），窗口高度不足时内部滚动，不会挤压窗口尺寸。

## 4. 检测窗口尺寸稳定性（本次修复 a429851）

- 原因：视频预览 `QLabel` 的 `sizeHint()` 由图像实际尺寸决定，检测帧图片较大时会顶大布局最小尺寸，导致预览区/窗口被撑动。
- 修复：`_video.setSizePolicy(QSizePolicy.Ignored, QSizePolicy.Ignored)`，图像只随可用空间等比缩放，不再参与布局计算 → 窗口尺寸稳定。
